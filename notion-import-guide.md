# PANDUAN IMPORT NOTION — AI Tools Directory 2025

## Langkah-Langkah Import Data ke Notion

### Step 1: Buat Akun Notion
1. Buka https://notion.so
2. Klik "Get Notion free"
3. Daftar dengan email atau Google account
4. Login ke workspace Anda

### Step 2: Buat Database Baru
1. Di sidebar kiri, klik "+ New page"
2. Pilih "Database — Full page"
3. Beri nama: "AI Tools Directory 2025"

### Step 3: Setup Kolom Database
Buat kolom-kolom berikut (urutan penting):

| Nama Kolom | Tipe | Keterangan |
|---|---|---|
| Nama Tool | Title | Nama tools |
| Kategori | Select | Content Creator, Developer, Marketer, Desainer, Bisnis, Pendidikan |
| Sub-Kategori | Select | Copywriting, Visual AI, Video, Audio, Code, Testing, DevOps, Ads, SEO, Email, Social Media, Chatbot, UI/UX, 3D, Image Editing, Illustration, Productivity, Meeting, Automation, Finance, HR, Tutor, Language, Research, Study, Grading, Homework |
| Harga | Select | Free, Freemium, Paid |
| Harga Detail | Text | Detail harga (contoh: "Free / $20/bln") |
| Rating | Select | 1, 2, 3, 4, 5 |
| Best For | Text | Deskripsi singkat "best for apa" |
| Link | URL | Link website tools |
| Status | Select | Active, Inactive |

### Step 4: Import Data
1. Di database Notion, klik "•••" (titik tiga) di kanan atas
2. Pilih "Import"
3. Pilih format "CSV"
4. Upload file CSV (akan saya buatkan terpisah)
5. Notion akan otomatis mapping kolom

### Step 5: Atur View & Filter
Buat beberapa view untuk kemudahan:

**View 1: "Semua Tools"**
- Default view, tampilkan semua
- Sort by: Rating (descending)

**View 2: "Free Tools Only"**
- Filter: Harga = "Free"
- Sort by: Rating (descending)

**View 3: "Per Kategori"**
- Group by: Kategori
- Sort by: Nama Tool (A-Z)

**View 4: "Top Rated (4-5 Stars)"**
- Filter: Rating ≥ 4
- Sort by: Rating (descending)

### Step 6: Share Database
1. Klik "Share" di kanan atas
2. Klik "Publish"
3. Pilih "Share to web"
4. Copy link — ini yang akan Anda jual

### Step 7: Export PDF
1. Klik "•••" di kanan atas database
2. Pilih "Export"
3. Pilih format "PDF"
4. Klik "Export"
5. File PDF akan terunduh

---

## TIPS:

- **Update rutin:** Setiap bulan, tambahkan tools baru dan hapus yang sudah mati
- **Notion free** cukup untuk 100+ tools
- **Link share** bisa di-set sebagai "Allow duplicate as template" — pembeli bisa duplicate ke workspace mereka sendiri
- **Harga jual:** Rp99.000 untuk akses link Notion + PDF

## ALTERNATIF: Import via CSV

Jika import JSON tidak bisa, saya juga sediakan versi CSV:

1. Buka Google Sheets
2. Import file CSV
3. Copy-paste data ke Notion secara manual (cukup 10-15 menit)
